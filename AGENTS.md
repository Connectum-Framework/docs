# Documentation workspace

Read the applicable section before changing documentation or diagrams.

| Work | Required guidance |
|---|---|
| Content, navigation, examples | [Documentation style guide](en/contributing/documentation-style.md) |
| Isometric figures and composition plates | [Isometric composition style](en/contributing/documentation-style.md#isometric-composition-style), with [Server](en/guide/server.md) as the visual reference |

Use the shared isometric renderer named in that guide. Do not create a separate
projection or palette for a new page. Preserve existing diagrams and their
meaning; removal requires the user's agreement.
