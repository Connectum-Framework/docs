# Deploy

Start with a reproducible container image and the configuration the process
needs at startup. On Kubernetes, connect resource limits, health probes and
termination timing to the application's real lifecycle.

Add a gateway when clients need routing or transcoding at the edge. Add a service
mesh when your deployment needs its traffic and security policy; it is not a
prerequisite for running Connectum.
