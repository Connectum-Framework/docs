# Advanced

Use these guides when a runtime boundary or extension point affects your design.
Architecture explains how the process is composed. Guarantees and limits names
the prerequisites and evidence behind the behavior you can rely on.

Runtime compatibility distinguishes published-package requirements from direct
TypeScript execution. Custom protocols explains how to extend server
registration without changing the core. Local and remote call mechanics belong
in [Communication](/en/guide/communication).
